# My Personal AI

A separate, mobile-first personal workspace with a premium dark interface.

## Included in this first build
- English and Urdu interface toggle
- Responsive dashboard
- Personal planner with device-local task storage
- Wardrobe/style notes stored locally
- Quick notes stored locally
- PWA manifest, app icon and service-worker offline shell

## Run locally
Serve this folder using any static HTTP server, or publish it with GitHub Pages. The install option appears in supported browsers when the app is served over HTTPS.

## Important
The AI Assistant screen is intentionally marked as not connected. Live AI requires a secure backend and an AI provider API key. Do not put secret API keys in browser JavaScript or commit them to this repository. See [AI-SETUP.md](./AI-SETUP.md).

This is a standalone project. It does not depend on or modify the ICS Study Group project.
